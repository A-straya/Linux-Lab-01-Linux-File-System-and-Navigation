#  Mission Brief

Welcome to your first day at **ABC Technologies**.

Instead of reading documentation, your team lead gives you direct access to a Linux workstation and a single instruction:

> **"Build the company's workspace exactly as requested. No graphical interface. Terminal only."**

Every action you perform will be executed from the command line.

Failure means rebuilding the environment from scratch.

---

#  Your Mission

Design the company's workspace using only Linux commands.

By the end of this mission you should be comfortable navigating directories, organizing files and understanding how Linux stores information.

#  Commands Used

|----------|----------|

| File Management | `touch` `cp` `mv` `rm` |
| Directories | `mkdir` `rmdir` |

| Utilities | `history` `clear` `tree` |
